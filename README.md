# SSEPS Website

A responsive static homepage concept for Somali School of Economics and Political Science, inspired by the visual direction requested by the user.

## Run locally
Open `index.html` in your browser. Internet is needed for Google Fonts and the externally hosted Unsplash photos.

## Deploy to Vercel
1. Upload the contents of this folder to a GitHub repository.
2. In Vercel, choose **Add New → Project** and import that repository.
3. Choose **Other** if Vercel asks for a framework. Leave Build Command empty and Output Directory empty for a static HTML site.
4. Deploy.

Alternatively, install Vercel CLI and run `vercel --prod` from this folder.

## Before publishing
- Replace `admissions@sseps.example`, `research@sseps.example`, and `info@sseps.example` with real institutional addresses.
- Replace the example/stock images with approved SSEPS photography.
- Confirm programme details, official name, admissions process, location and social links.
- This is a frontend template. It does not yet include a database, CMS, application form processing, student portal or admin dashboard.
